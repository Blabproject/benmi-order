套餐組合設定指南與實例
深入了解套餐概念、3步驟設定流程與常見餐飲實例
概念

1. 套餐組合 (Combo / Bundle) 是什麼？

套餐組合是將多樣餐點（如：主餐 + 配菜 + 飲料）綁定在一起以固定套餐價販售的功能。顧客在手機（LINE LIFF）或店員於 POS 點餐時，需依各群組規定選滿指定數量方可加入購物車。此功能有助於提高客單價、加快出單與備料流程。

流程

2. 套餐設定 3 步驟

步驟 1
新增自選分組
點擊左側「+ 新增自選分組」，設定繁中與越南語名稱（例：請選擇 1 樣主餐、請選擇 6 樣配菜）。
步驟 2
設定數量與重複規則
使用 [ - ] 和 [ + ] 調整顧客必須選滿的數量。若顧客可重複選相同品項（如：2 份玉米筍），請勾選「允許重複選同一品項」。
步驟 3
指定選菜來源
可選擇「依整個分類自動匯入」（如：所有蔬菜類或飲料類），或切換至「手動勾選特定品項」。
範例

3. 常見餐飲實例 (Example Use Cases)

🍗 鹹水雞 / 滷味 / 炸物店實例 (例：蔣姐姐鹹水雞)
1 組 • 6 樣菜
品項：套餐 A (3隻鹹水雞翅+6樣菜) - $150
設定：建立 1 個自選分組「請選擇 6 樣配菜」，需求數量設為 6，勾選「允許重複選同一品項」。選菜來源勾選「海裡」、「時蔬」、「內臟」、「滷味」等分類。
🥖 越式法國麵包 / 早午餐 / 輕食店實例
2 組 • 主餐 + 飲料
品項：元氣早午餐特惠套餐 - $99
設定：
• 分組 1：「選 1 樣主餐麵包」（數量 = 1，來源：法國麵包分類）
• 分組 2：「選 1 杯飲品」（數量 = 1，來源：咖啡與茶飲分類）
🍲 火鍋 / 燒烤 / 雙人便當店實例
3 組 • 湯底 + 肉品 + 副餐
品項：雙人特選火鍋套餐 - $450
設定：
• 分組 1：「選 1 款湯底」（數量 = 1，來源：原味、麻辣、番茄等）
• 分組 2：「選 2 盤肉品」（數量 = 2，允許重複，來源：牛肉片、豬五花、雞腿肉）
• 分組 3：「選 2 樣副餐」（數量 = 2，來源：白飯、冬粉、王子麵）

✕
1. 列印出單模式
確認後自動列印
客人送出訂單後，系統先發出提示音。店員檢查內容並確認接單成功後，才自動列印「1 張收銀明細」與「全部餐點貼紙」。店員自行建立的訂單，送出即視為確認。
自動接單並列印
啟用並設定至少一台印表機後，系統會自動接受並列印待確認的新訂單。加點或已修改的訂單仍由店員確認。
手動列印模式 (Manual-print)
收到新單時僅發出通知音，店員需點進訂單詳細頁確認餐點內容後，點選 [整單全印] 才會出單。適合需先確認庫存或客製化說明門市。
2. 訂單詳細頁 3 段式列印控制
整單全印 (明細+標籤）
一鍵送出：1 張櫃檯明細 (給客人或留底) + N 張廚房貼紙 (每份餐點 1 張獨立杯貼/盒貼)。
僅印收銀明細
僅出單張收據小票，適合結帳找零、補開客人明細或退換貨核對。
單品貼紙列印與備餐勾選
每道餐點左側設有 [ ] 勾選方塊供廚房備餐核對；右側設有 [印單品貼紙] 鈕，遇卡紙或貼紙破損時可單獨補印該品項。
補印客製/緊急貼紙
點開可快選常見備註 (如：不要香菜、去冰、微辣) 或手動輸入特殊要求，立即印出獨立小貼紙貼在餐盒上。
3. 雙印表機 (Dual-Station) 建議設定
• 櫃檯印表機：建議使用 ESC/POS 協定熱感應小票機 (80mm 或 58mm)，連接 Wi-Fi (Port 9100) 或藍牙。
• 廚房/吧台印表機：建議使用 TSPL 協定標籤貼紙機 (如 Aimo, Xprinter 40x30mm / 50x30mm)，模式選「單品/杯貼標籤」。
• 每日開班前建議點選「測試列印」確認連線通暢。
